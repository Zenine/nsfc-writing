# 英文题目与英文摘要

英文题目和英文摘要在信息系统中单独填写，评审和管理人员都会看到。要求是与中文**完全对应**、读起来像英文论文而不是逐字翻译。

## 英文题目

- 与中文题目的对象、科学问题、方法一一对应，不增加中文没有的限定。
- 用名词短语，不用 “Study on”“Research on”“Investigation of” 开头；必要时用 “Mechanism of …”“… controlling …”“… via …” 等结构。
- 实词首字母大写或句首大写，全文统一一种风格；化学式、物种名按学科规范书写。
- 给 1—2 个版本，说明各自的取舍。

## 英文摘要

- **内容对应**：逐句对应中文摘要，不增删事实，不新增数字、结论和意义；中文改了，英文同步改。
- **结构**：一段；分层用 First, … Second, … Finally, … 或 (1)(2)(3)，与中文分层一致。
- **时态**：背景与已有认识用一般现在时；前人具体工作用一般过去时或现在完成时；本项目工作用 “This project will …”“We will …”“aims to …”。
- **术语**：核心术语全文同一译法（如 sediment–water interface 不与 sediment/water boundary 混用）；中文领域内有通行英文名的用通行名，拿不准的列入【待核】。
- **长度**：以系统限制为准；写完报告英文词数或字符数。
- 避免中式结构：长串定语前置、“the research of”“make a study”、每句都以 “This project” 开头。

## 输出

判断行 → 英文题目（附取舍说明）→ 英文摘要（附词数）→ 中英对照中需要申请人确认的术语清单 → 待核与待补（提醒中英文摘要须一致、长度限制以系统为准）。
