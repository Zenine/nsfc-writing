# 年度研究计划与预期成果

评审很少因为计划写得好而加分，但计划写错会给自己埋坑（结题完不成指标）。目标是：与研究内容对应、体量合理、指标留有弹性。

## 年度计划

- 按年度写，具体到起止月份；每年一个重点，与研究内容的先后逻辑一致，三年逐步收敛到完成。
- 每年包含：研究任务、阶段产出、学术交流（参加会议、做报告）、阶段总结。
- 可按四条线递进安排：理论或机制研究 → 模型或方法验证 → 实际数据或场景检验 → 阶段总结与结题。
- 版面紧张时不必放进度甘特图。

## 预期成果

- 先写科学认识：揭示什么机制、建立什么模型或判据、形成什么数据集；再写论文、专利、人才培养。
- 指标留弹性：写“发表高水平学术论文 3 篇以上”，不承诺“5 篇一区顶刊”。
- 专利写“申请”，不写“授权”（授权周期常超过项目期）；论文写“投稿/发表”，不写已接收。
- 注意当年政策对国内期刊成果比例的要求（近年要求部分成果发表在国内期刊）。
- 人才培养按项目性质写：偏基础写“培养研究生×名”，偏应用可写“培养具备工程实践能力的技术人员”。
- 成果体量与资助额度相称，不写“支撑某区域全面治理”一类超出项目的贡献。
