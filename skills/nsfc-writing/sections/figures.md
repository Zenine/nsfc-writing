# 配图

## 每张图回答一个问题

| 图 | 回答的问题 |
|---|---|
| 框架图 | 全项目由哪几块组成、各自回答什么、彼此怎么连接 |
| 技术路线图 | 从样品或数据到结论，经过哪些步骤、用什么方法、结果流向哪里 |
| 缺口示意图 | 已有认识覆盖到哪里、缺口在哪一环 |
| 成果组图 | 申请人已有的关键发现 |

框架图的元素就是工作表的格子：科学假说、关键科学问题、研究内容、核心方法，以及它们之间的连线。工作表里没有的东西不进框架图。

## 检查

- **与正文一致**：图中模块的名称、编号、数量与正文完全相同；正文改了，图跟着改。
- **流向清楚**：箭头表示数据或逻辑的流向，读向固定；反馈回路用不同线型并加说明。
- **同一含义用同一视觉编码**：同一项研究内容在全本所有图里用同一颜色或形状；强调只用一种方式。
- **按实际版面大小检查可读性**：缩到申请书中的实际尺寸后，最小的字和最细的线仍然看得清。

## 真实性

- 实验图、数据图、仿真结果图只用真实结果，不用生成式工具生成。
- 框架图、技术路线图等概念示意图：可以用生成式工具或脚本出草图帮助确定逻辑和版式，最终由申请人用绘图软件重新绘制。agent 出草图时，保证逻辑、结构和文字逐字准确。
- 引用他人的图要重新绘制并注明来源。
