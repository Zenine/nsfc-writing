# 立项依据

## 这一部分要让评审相信什么

这个问题真实存在，背后有一个尚未解决的科学本质；已有研究没有解决它，是因为某个具体原因；申请人找到了绕过这个原因的办法。

## 论证链

立项依据沿工作表的格子推进，共四步。小标题用陈述句写出该段结论，编号与层次按当年模板。

1. **问题与本质**：研究对象和它面临的真问题；政策背景一两句即可；本段收在问题的科学本质上。
2. **已有认识**：按观点、方法路线或研究阶段归类，每一类写清把认识推进到了哪里、依据是什么、在什么条件下成立。每一类末尾一句小结。
3. **卡在哪里、为什么**：各类工作共同没有解决的环节，以及原因（方法限制、尺度不匹配、数据缺失、假设不成立等）。这是立项依据中最关键的论点。这里只写原因，不写假说。
4. **本项目的判断**：针对第 3 步的原因，写出新切入、科学假说（全本完整的假说句只在这里出现一次）、要回答的问题和预期认识；用一句话说明新切入依赖申请人已有的哪些方法、数据或样本。目标导向类在此写明成果对应的需求。

写完后用 `references/diagnosis.md` 的对应表核对：第 3 步指出的每个原因，研究内容里都有对应的工作；研究内容不处理的问题，第 2、3 步没有展开。

## 文献

- 以近年高水平工作为主，保留必要的奠基性工作；同方向有代表性的研究组要提到，避免被认为遗漏重要工作；自引适度。
- **用户提供的文献不足时**：按已有材料写到论证完整为止，不用泛泛论述凑篇幅；缺文献的位置留【待补文献：方向＋中英文检索词】，在待核清单里写明还缺哪几类、各大约几篇。
- 说某个环节“尚无研究”，必须有检索支撑；把握不足时写“对××环节尚缺乏定量认识”，并给申请人列出中英文检索词。

## 版式

- 每段只讲一个意思，段末一句点明结论。
- 全文只用一种方式突出重点，少量使用；不加粗“问题：”“根源：”这类标签式导语。
- 一张示意图（已有认识覆盖到哪里、缺口在哪一环）往往比一段文字更清楚。

## 自检

- 只读每段末句，能否连成一条完整的论证？
- 第 4 步的新切入是否正好针对第 3 步的原因？
- 有没有大段政策表述、“随着我国经济社会快速发展”式开头、“填补空白”“国际领先”、风险与“不重叠”声明？
