# 用往年结题报告做参考

## 去哪里找

国家自然科学基金基础研究知识库（kd.nsfc.cn）公开已结题项目的信息：项目名称、负责人、依托单位、批准年度、资助类别、申请时的摘要、结题摘要和结题报告全文。可以按关键词、申请代码、资助类别、年度检索。

查看结题报告全文需要先在网页上完成滑块验证。本 skill 不提供自动下载：请用户在浏览器中检索、通过验证后，逐页保存报告图片到本地一个目录（每个项目一个目录，文件名带页码），再用

```
python3 scripts/merge_pages.py 报告图片目录 --name "项目名称"
```

合并成一个 PDF。脚本只处理本地文件，不访问网络；需要 Pillow。

报告供个人学习参考，按网站使用条款使用；报告里有他人的姓名、单位和成果，留在本地私有目录，不放进公开仓库，不对外分发。

## 选哪些项目

- 同一申请代码、相同资助类别、近几年结题的项目。
- 研究对象或方法与本项目相近，但不必完全相同：看别人怎样把相近的问题收窄成一个项目。
- 每次挑三五个即可，宁精勿多。

## 读什么

| 看什么 | 用来判断 |
|---|---|
| 题目与申请时摘要 | 同类项目把问题收窄到什么程度；题目里放了哪些要素 |
| 申请时摘要与结题摘要的差别 | 计划与实际完成之间常见的落差，哪些承诺偏大 |
| 结题报告中的研究内容与完成情况 | 同类资助额度下实际做得完的体量 |
| 成果清单 | 量力承诺的参照：同类项目实际产出的论文、专利数量与类型 |
| 遇到的问题与调整 | 风险应对可以预先考虑哪些情况 |

## 不该怎么用

- 结题报告是事后总结，结构与申请书不同，不照搬其章节结构。
- 不照抄文字；借鉴的是收窄问题的方式和体量判断。
- 引用其中的研究结果，按正式发表的论文引用；没有正式发表的，不作为本项目的文献依据。
- 别人的成果不写进本项目的研究基础。

## agent 读报告时的输出

用户提供本地报告（PDF 或图片目录）后：

1. 逐份列出：项目名称、资助类别与年度、研究内容项数、关键科学问题（如报告中写明）、主要成果类型与数量。
2. 横向比较：与本项目在问题收窄程度、体量、方法上的异同。
3. 对本项目的具体建议，每条注明依据来自哪份报告的哪一部分。
4. 报告中看不清或缺页的部分标【待核】，不补写。
