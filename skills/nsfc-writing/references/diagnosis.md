# 诊断本子：症状、原因与改法

诊断前先核对材料本身：用户给出本地文件或目录时，检查正文引用的图片、附件路径是否存在；图号、式号、研究内容编号的交叉引用是否一致；研究内容之间的引用是否与编号顺序一致。

诊断时按严重程度分三级报告：**致命**（足以否定全本：没有科学问题、逻辑断裂、硬性违规）→ **严重**（明显扣分：结构、对应关系、夸大、超出建议篇幅）→ **一般**（语言、格式、细节）。每条写“位置—问题—为什么扣分—怎么改”。

## 常见症状

| 症状 | 典型表现 | 根源 | 改法 |
|---|---|---|---|
| 流水账 | 研究内容是“制备—表征—试验—验证—规程”；进展是“某某研究了……”逐条罗列 | 没有假说，只有任务 | 先填工作表、写出假说，内容改为回答假说的子问题；进展按观点归类 |
| 没亮点 | 读完说不出与别人有什么不同 | 新切入与问题本质的关系没写出来；创新是研究内容换个说法 | 写清新方法为什么能作用于本质；创新对应困难；1.4 写“为什么是你” |
| 太技术 | 目标是“建立预测模型/平台/规程”；用词多为开发、优化、工艺 | 停在技术层，没拆到科学本质 | 把指标背后的底层过程找出来；目标改为阐明机制，应用放到意义里 |
| 像综述 | 立项依据讲整个领域发展史，与本项目无关的内容多 | 没有先定故事线 | 只保留为本项目科学问题铺路的文献，每段末尾一句结论 |
| 问题空泛 | “缺乏系统研究”“仍是黑箱”“机制尚不明确”而无具体环节 | 没追问到底 | 写出具体缺哪一环、为什么缺（方法限制、尺度不匹配、数据缺失） |
| 前后脱节 | 立项依据列五个问题，只做其中一两个；技术细节与研究内容对不上 | 写完各节没有对照 | 做对应表：问题→内容→目标→技术细节→创新→基础 |
| 防御性写作 | “需要说明的是”“与在研项目不重叠”“可能存在风险，将尽最大努力” | 把顾虑写进了正文 | 删除；区别说明放到“在研项目”栏一句写清，风险放到风险应对栏写预案 |
| 口号与拔高 | “形势严峻，刻不容缓”式小标题；“填补空白、国际领先” | 用情绪代替论证 | 小标题写信息；用证据说明价值 |
| AI 味 | 处处“全面、系统、深入”，分点小黑点，对仗排比，方案只说用什么 | 内容不具体 | 见 wording.md“去除 AI 味” |
| 数字堆砌 | 摘要塞满百分比、样本量、前期发表数 | 把证据和结论放错位置 | 摘要最多一个关键事实；证据放立项依据和研究基础 |
| 体量失衡 | 青C 写 4—5 项内容；三项内容篇幅七成、两成、一成 | 选题未收窄 | 合并或删减到 2—3 项，篇幅均分 |
| 时态错误 | 研究方案写成“已经完成了……” | 把基础当计划 | 方案用将来时；已有结果移到可行性分析 |
| 开头堆数据 | 研究内容或立项依据某段连列多项前期数字 | 把证据当主线 | 开头只留一句定性判断，数字移到研究基础的初步结果 |
| 编号倒挂 | 内容二使用内容三的结果，方案与年度计划顺序又是一、三、二 | 编号未按数据流向排 | 按数据流向重排编号，目标、关键科学问题对应关系同步调整 |
| 绝对断言 | “从未有人关注”“首次提出”“国内外空白” | 未检索就下结论 | 改为有限定的说法；给出中英文检索词，请申请人检索相近工作 |
| 引用失效 | 图片路径不存在、图号跳号、正文说“见图2”而图2不是该内容 | 改稿后未同步 | 列出失效的引用与现有文件名，逐一对齐 |

## 硬性违规（列为致命）

- 删改提纲标题或括号文字。
- 参考文献检索不到（疑似编造）。
- 实验图、数据图来源不真实。
- 代表作虚标第一或通讯作者、夸大贡献。

正文明显超出“原则上不超过 30 页”列为严重；参考文献作者、期卷号等格式错误列为一般。

## 诊断输出模板

1. 判断行。
2. 一句话总评：本子目前最大的问题是什么。
3. 问题清单（致命 → 严重 → 一般）。只报确实存在的问题，用户原文已经满足的要求不列。
4. 改写示例：挑问题最集中的一段改写，不编造文献，用【待补文献】占位。
5. 待核与待补。
