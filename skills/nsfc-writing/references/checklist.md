# 提交前自查清单

逐项给出“通过／不通过（位置）”，不通过的列入待改清单。

## 一、主线

- [ ] 能用一句话说出科学假说（理论类项目为待证命题），且可检验。
- [ ] 关键科学问题落在机制、规律或定量关系上，数量与项目类型相称。
- [ ] 题目、摘要、立项依据末段、研究内容、关键科学问题、技术路线、创新、研究基础说的是同一个科学问题。
- [ ] 立项依据提出的每个问题都有研究内容回应；不做的问题前面没有展开。
- [ ] 研究内容与研究目标数量相同、顺序一致；技术细节按研究内容的编号逐项展开。

## 二、各部分

- [ ] 题目：25 字以内，含科学问题与具体方法，“的”不超过 2 个，无问句和口号词；英文题目与中文对应。
- [ ] 摘要：一段、380—400 字（或系统上限内写满）、首词为研究对象、方案分层与研究内容对应；无数字堆砌和拔高；英文摘要与中文一致。
- [ ] 立项依据：背景—进展—问题—本项目思路四段齐全，写了“为什么由申请人来做”；进展按观点归类；“尚未触及”有文献支撑。
- [ ] 研究内容：只写做什么；无制备表征、工艺优化、技术规程类单列项；各项篇幅均衡。
- [ ] 研究方案：总述与总图同页；拟开展的工作用将来时；已完成的结果放在研究基础。
- [ ] 特色与创新分开写；创新 2—3 条，每条对应一个困难，用预期语气。
- [ ] 年度计划按系统生成的研究期限分年度、到月份；专利写“申请”，论文指标留弹性。
- [ ] 研究基础：研究积累按研究内容分条；可行性用近期结果；风险 2—3 条且有备选方案；申请人与团队分开写。
- [ ] 正在承担的项目写区别，已完成的项目写联系；无相关项目或无其他说明事项处保留标题写“无”。
- [ ] 代表作本人贡献写到具体工作，署名如实。
- [ ] 预算制项目：预算科目与研究方案逐项对应，有测算依据。

## 三、形式与合规

- [ ] 提纲标题与括号文字与系统模板一致，未删改。
- [ ] 正文在 30 页以内（以当年要求为准）。
- [ ] 在系统生成的 PDF 上检查：无错别字、乱码、错位；图表编号与正文引用一致；图表不跨页。
- [ ] 全文只用一种突出方式，只突出整句结论。
- [ ] 参考文献格式统一，每篇已由申请人检索核实。
- [ ] 图件风格统一；实验图、数据图来自真实结果。
- [ ] 申请代码、关键词、研究属性与内容一致。
- [ ] 生成式人工智能使用情况已按当年要求声明与标识。
- [ ] 申请材料已征得主要参与者和合作单位同意；涉及伦理敏感领域的已通过伦理审查；无涉密内容；职称如实。

## 四、读者测试

- [ ] 一位同行读完，能说出科学问题和创新点。
- [ ] 一位非本方向的读者能读懂立项依据和摘要；读不通的句子改写。
- [ ] 往年未获资助的，评审意见已吸收进正文。
