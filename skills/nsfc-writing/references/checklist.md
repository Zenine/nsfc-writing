# 提交前自查清单

逐项给出“通过／不通过（位置）”，不通过的列入待改清单。

## 一、往年意见

- [ ] 往年未获资助的，每条评审意见都已在正文中得到处理（不是逐条答复，而是改在对应位置）。

## 二、工作表是否贯穿全本

- [ ] 科学假说（理论类项目为待证命题）能用一句话说出，并说得出什么结果会否定它。
- [ ] 立项依据第 3 步指出的原因，与新切入正好对应；第 3 步的每个原因，研究内容里都有对应的工作。
- [ ] 关键科学问题是问句，问的是未知的关系或机制。
- [ ] 题目、摘要、立项依据第 4 步、研究内容、关键科学问题、框架图、技术路线图、创新、研究基础用同一组核心词，说的是同一个假说。
- [ ] 研究内容与研究目标一一对应；研究方案和年度计划沿用研究内容的编号；反馈关系已标明。

## 三、各部分

- [ ] 题目：读一遍能说出对象、科学问题、方法；地区和省级项目保留本地特色对象词。
- [ ] 摘要：一段、不超限；只读摘要能写出假说；做法覆盖每一项研究内容；英文摘要与中文一致。
- [ ] 立项依据：四步论证完整；完整的假说句只出现一次；“尚无研究”有检索支撑；文献每篇已由申请人检索核实。
- [ ] 研究内容：每项标题是要回答的问题；删掉任何一项假说就检验不了；没有任务名式的单列项。
- [ ] 研究方案：每个要点写出了“成立时看到什么、不成立时看到什么”；拟开展的工作用将来时。
- [ ] 特色与创新：每条创新都能指出被修正或扩展的已有结论；用预期语气。
- [ ] 年度计划：按系统生成的研究期限、按依赖关系排序；预期成果都能对应到研究内容。
- [ ] 研究基础：证据按研究内容组织并标明状态；结论不超出数据；本人角色如实；风险有备选方案。
- [ ] 工作条件：涉及人体或动物的，写明伦理审查情况。
- [ ] 在研项目：逐个写明本项目哪些内容不在其任务书范围内；无相关内容处保留标题写“无”。
- [ ] 代表作：本人贡献写到具体工作，署名如实。
- [ ] 配图：图中名称、编号与正文一致；缩到实际尺寸仍可读；实验图、数据图来自真实结果。
- [ ] 预算制项目：预算科目与研究方案逐项对应，有测算依据。

## 四、合规

- [ ] 提纲标题与括号文字与系统模板一致；正文不超过当年规定的页数。
- [ ] 申请代码、关键词、研究属性与内容一致。
- [ ] 生成式人工智能使用情况已按当年要求声明与标识。
- [ ] 申请材料已征得主要参与者和合作单位同意；无涉密内容；职称如实。
