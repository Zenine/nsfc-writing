# 提交前自查清单

逐条打勾。不满足的项列入待改清单，注明位置。

## 主线与对应

- [ ] 能用一句话说出科学假说，且可检验。
- [ ] 关键科学问题是“如何……”问句，落在机制、规律或定量关系上，数量符合项目类型。
- [ ] 题目、摘要、立项依据末段、研究内容、关键科学问题、技术路线、创新、研究基础对得上。
- [ ] 立项依据提出的每个问题都有研究内容回应；不做的问题前面没有展开。
- [ ] 研究内容与研究目标数量相同、顺序一致；技术细节与研究内容小点一一对应。

## 各部分

- [ ] 题目：25 字左右以内，“的”不超过 2 个，含具体方法，无问句和口号词。
- [ ] 摘要：一段、写满字数、首词为研究对象、方案分层、末句“旨在……以期……”，无数字堆砌和拔高。
- [ ] 立项依据：四段齐全，含“为什么是你”；进展按观点归类；“没人做”有文献支撑。
- [ ] 研究内容：只写做什么；无制备表征、工艺优化、技术规程类单列项；各项篇幅均衡。
- [ ] 研究方案：总述与总图同页；将来时；公式和数据只在这一部分。
- [ ] 特色与创新分开写；创新 2—3 条，每条对应一个困难。
- [ ] 年度计划到月份；专利写“申请”，论文指标留弹性。
- [ ] 研究基础写过去，可行性写未来；风险应对 2—3 条且有预案；个人与团队分开写。
- [ ] 在研项目写区别，已完成项目写联系；无项目处保留标题写“无”。
- [ ] 代表作本人贡献具体到技术层面，署名如实。

## 形式

- [ ] 正文不超过 30 页（或当年规定）；提纲标题与括号文字未改动。
- [ ] 看导出后的 PDF 版本：无错别字、乱码、错位。
- [ ] 图表编号与正文引用一致；无图表跨页；图名完整。
- [ ] 全文只用一种突出方式，只读突出句也能读懂每页。
- [ ] 参考文献格式统一，每篇已由申请人检索核实。
- [ ] 所有图风格统一；实验图、数据图来自真实结果。
- [ ] 申请代码选到二级，关键词准确，研究属性选择与写法一致。
- [ ] 生成式人工智能使用情况已按当年要求处理。

## 读者测试

- [ ] 请一位同行通读：能否指出科学问题和创新？
- [ ] 请一位外行通读：读不通的句子改写。
- [ ] 放几天后再读一遍。
- [ ] 往年未获资助的，评审意见已逐条吸收进正文。
- [ ] 确认上传的是最终版本。
