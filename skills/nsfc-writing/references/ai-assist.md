# 借助大模型提升本子

原则：大模型用来发现问题、梳理文献线索、提供对照；科学问题由申请人决定，关键科学问题、核心段落和图由申请人改写定稿，不直接提交模型生成的申请书。

## 适合做的

- 梳理某领域的研究脉络和观点分歧，结果只作线索，文献逐篇核实。
- 按工作表逐格追问，找出论证薄弱处。
- 分析一篇写得好的获资助摘要好在哪里，再由申请人按同样的逻辑改写自己的段落。
- 把往年评审意见逐条对应到正文位置。
- 只标问题、不改文字：让模型列出不通顺、前后矛盾、术语不一致的位置，由申请人自己改。

## 按工作表追问

让模型站在挑剔的同行评审角度，逐格提问，每格要求它指出最薄弱的一点：

| 工作表格子 | 追问 |
|---|---|
| 真问题 | 这个问题真实存在吗？证据是什么，范围有多大？ |
| 科学本质 | 问题背后的底层过程说对了吗？有没有更深一层的决定因素？ |
| 已有认识与局限 | 有没有遗漏的重要工作？说“尚未解决”站得住吗？ |
| 新切入 | 为什么这个方法能作用到科学本质上？别人为什么没这样做？ |
| 科学假说 | 什么结果会推翻它？预期方向写清楚了吗？ |
| 关键科学问题 | 它是认识难点还是操作困难？答案会是机制、规律还是一套系统？ |
| 研究内容与方案 | 每项内容都在检验假说吗？哪一项做不出来时全项目会失败？ |
| 为什么是你 | 换一个同行来做，差别在哪里？ |

模型给出的关键科学问题往往停在表层，适合作为讨论起点；经过几轮追问后由申请人自己凝练。

## 按往年评审意见修改

把意见按“科学问题、创新、方案、基础、写作”归类；每条意见找到正文中的对应位置并修改，在给申请人的说明中列出“意见—修改位置—修改方式”对照表。正文里吸收意见，不写成逐条答复。

## 边界

- 不把整本申请书、全部技术细节和核心数据交给在线模型；按段落、以讨论方式使用。
- 参考文献逐篇在数据库中检索核实，不使用未核实的模型给出的文献。
- 实验图、数据图不用生成式工具生成。
- 使用情况按当年通告声明和标识。
