# 科学问题工作表与主线链条

基金资助的是技术和工程背后的科学。评审最常见的否定意见是“科学问题凝练不够”“没有假说，先做做看”。本子写成任务清单、像流水账，根源几乎都在这里。

## 主线链条

```
真问题（行业痛点、技术瓶颈、现场反常现象）
  → 科学本质（底层的物理、化学、生物或系统过程）
  → 已有认识的局限（前人卡在哪一环、为什么卡住）
  → 新切入（新方法、新视角、新体系、新模型、新数据）
  → 科学假说（施加新切入后，本质过程会怎样变化；一句话、可检验）
  → 关键科学问题（青C 1—2 个，面上 2 个左右）
  → 研究内容（青C 2—3 项，面上 3—4 项）与研究目标一一对应
  → 研究方案、技术路线、创新、研究基础逐条呼应
```

## 工作表

起草新章节或整本前先填，并放在回复中正文之前。

- 研究对象、科学本质或新切入缺失，拟不出假说时：先就这几格向用户提问，暂不写正文。
- 只缺支撑证据、文献或细节时：照常写初稿，缺的格子标【待补】。

| 格子 | 要回答的问题 |
|---|---|
| 研究对象 | 一个具体对象，加足定语（什么体系、什么条件、什么尺度） |
| 真问题 | 现实中出了什么问题；最多一个关键事实或数字说明它重要 |
| 科学本质 | 问题背后是哪个底层过程；把二级学科术语拆到一级学科的基本过程为止 |
| 主导尺度与关键结构/过程 | 哪个尺度上的什么结构或过程起决定作用；不是越微观越好 |
| 已有认识与局限 | 前人做到哪一步、靠什么方法；没解决的部分卡在哪个环节、原因是什么 |
| 新切入 | 本项目的新方法或新视角是什么；它为什么能作用到上面的科学本质 |
| 科学假说 | 一句话：在什么条件下，什么因素通过什么过程导致什么结果；能被实验或观测检验。数学与理论类项目写待证命题或猜想 |
| 关键科学问题 | 从假说里挑出最难、最核心的一两处，写成“如何……”问句 |
| 研究内容 | 为检验假说必须回答的 2—3 个子问题 |
| 预期认识 | 做完后得到的新机制、新规律、新判据或新模型，再写应用价值 |
| 为什么是你 | 前期发现、独有数据或平台、方法积累中最硬的一两条 |

## 凝练的几个动作

- **拆本质**：问题落到能量传递、物质结构、反应转化、信息传递、组织机制中的哪一类，再加本选题专属的定语。例如“破乳效果差”落到“界面氢键网络与传质”，“预测不准”落到“哪个过程的参数化缺失”。
- **找关键环节**：表面关联是“改变操作 → 指标变化”；科学问题在两者之间：操作改变了哪个底层结构或过程，这个结构或过程又如何决定指标。
- **追问到底**：对每个候选问题继续问“它又由什么决定”，直到再往下拆就离开本项目的研究范围为止。
- **能力跃迁检验**：好问题能改写成“从 X 到 Y”（从定性到定量、从静态到动态、从经验到机制）。只能改写成“提高精度、完善方法”的，还没凝练到位。
- **排除平凡解释**：以反常现象立题时，写明它不是测量误差、采样偏差或已知因素造成的。
- **量化瓶颈**：说“瓶颈、失配、偏离”时给出量级或比值，只说“效果不佳”等于没证明。
- **以选题目标为准**：选题目标决定科学问题落在哪个学科，不死守自己学科的惯用口径。

## 科学、技术、工程的区分

- 科学回答“为什么、如何发生”；技术回答“用什么办法实现”；工程回答“如何集成落地”。
- 效率、去除率、精度、强度、成本、减排量是承载科学内涵的指标，不是研究中心。
- 研究内容停在“建系统、建平台、建模型、建规程、优化工艺”，就是把基础研究写成了应用开发。目标导向类也一样：落地写在意义和应用前景里，研究内容仍围绕机制。

## 假说的写法

- 句式：“本项目认为，在［条件］下，［因素］通过［过程/结构］调控［结果］。”
- 要有预期方向（增强还是削弱、哪类主导），才能被检验。
- 假说必须由前期证据或文献推理支撑，写清推理来自哪里；没有支撑的，标为待补。
- 数学、理论物理、算法理论等项目：用“待证命题（猜想）＋拟采用的证明或理论分析路线”代替实验假说，关键科学问题落在证明的难点上。
