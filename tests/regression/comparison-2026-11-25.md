# 基线与带 skill 对照（2026-11-25）

同一模型、同一输入；基线不加载 skill，带 skill 按 `SKILL.md` 路由加载。逐条对照 `tests/fixtures/` 的期望表现。

| 用例 | 基线（无 skill） | 带 skill |
|---|---|---|
| A 摘要 | 分三段；堆两个数字；方案用分号串联；目标落在“预测模型”；无待核清单 | 一段到底；首词为研究对象；“首先、其次、最后”分层；落脚机制与判据；末句“旨在……以期……”；列出待核来源。首轮 426 字超限，补“写到 380—400 字并报实际字数”后复测 |
| B 研究内容 | 保留 4 项，仍含“制备与表征”“田间验证与技术规程”；无单项结构；关键科学问题为陈述句 | 先写假说；收为 3 项，每项“界定—必要性—因此本项目拟—A/B/C”；目标 1:1；关键科学问题为“如何……是……关键科学问题”；技术规程移入应用价值 |
| C 诊断 | 找出流水账、空泛缺口、拔高、防御性文字、口号标题；改写示例沿用原文人名引文 | 按致命、严重、一般分级，每条写位置、原因、改法；补出缺少 1.3/1.4 与“为什么是你”；改写示例全部用【待补文献】占位 |
| D 新版提纲 | 正文结构答错；称青C 需要编预算；篇幅“十几页” | 按 2026 年度通告与提纲逐条答对：四部分结构、方案并入研究内容、可行性并入研究基础、30 页与篇幅分配、包干制不编预算；注明新年度需核对 |
| E 改题目 | 给出问句式题目；版本未逐一标字数 | 每版标字数和“的”数，无问句；首轮有一版不含方法，补“每个版本都含科学问题与方法”后复测 |
