**问题清单**

致命
1. 第二部分末段—缺口空泛，没有科学问题—“迁移转化行为黑箱”“缺乏系统研究”没有指出缺的是哪一环、为什么缺；没有新切入、没有假说。评审最常见的否定意见“科学问题凝练不够”就出在这里—先填工作表：研究对象（哪个单元、哪类基因载体）、科学本质（如基因水平转移或宿主增殖等具体过程，待你确定）、已有方法为什么看不到这个过程、新切入是什么；再按“问题与本质 → 已有认识 → 卡在哪里与原因 → 本项目的判断”四步重写。
2. 第二部分第一段—文献按“某人研究了某厂”逐条罗列—是流水账，不是对认识的归纳，评审看不出各类工作把认识推进到了哪里—按观点或方法路线归类（如单厂丰度测定、去除率比较、宏基因组表征），每类写清推进到哪里、依据与成立条件，类末一句小结，再指出这些路线共同没解决什么、原因是什么。

严重

4. 第二部分末段—“填补国内外空白”“国际领先”“重大的理论意义和应用价值”—无法核实的拔高，且是未检索就下的绝对断言—删除；用证据说明价值，缺口写成有限定的说法，并由你以中英文检索词检索后再下结论。
5. 第一部分—口号式小标题（“形势严峻，刻不容缓”“成果丰硕，但仍有不足”）与套话开头（“随着……快速发展”“广泛关注”“严重威胁”）—没有一个具体事实说明问题真实存在，政策表述占了篇幅—小标题改为陈述本段结论的句子；背景只留一个关键事实（保留原有范围）和一句政策，段末收到科学本质上。
